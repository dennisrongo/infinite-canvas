FEATURE #72: Note duplication (create copy of note) ✅ PASSING
-------------------------------------------------------------

Implementation Summary:

1. API Endpoint Created:
   - POST /api/notes/:noteId/duplicate
   - Creates a copy of the specified note
   - Verifies user owns the original note
   - Returns the duplicated note

2. Duplicate Logic:
   - Same content, title, font settings as original
   - Title gets " - Copy" suffix (unless already present)
   - Position offset by (50, 50) pixels down-right
   - New unique ID generated
   - Separate database record

3. UI Implementation:
   - Duplicate button added to NoteNode component
   - Button shows on hover OR when note is selected
   - Positioned top-right of note
   - Blue copy icon (#3B82F6)
   - Triggers duplication via callback chain

4. Component Chain:
   - NoteNode: Button in UI → data.onDuplicate(id)
   - ReactFlowCanvas: handleNoteDuplicate → onNoteDuplicate(noteId)
   - Canvas Page: handleNoteDuplicate → API call
   - API: POST /api/notes/:id/duplicate → Returns new note
