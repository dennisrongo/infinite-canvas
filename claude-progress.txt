Password Reset Token Flow:

2. System generates token, stores in password_reset_tokens table
3. Reset link logged to console (development): /auth/reset-password?token=XYZ
4. User clicks link → fills new password form → POST to /api/auth/reset-password

6. User redirected to login to authenticate with new password

3. POST to /api/user/change-password
4. System validates current password, validates new password strength
5. Updates user password in database
6. Session preserved (user remains logged in)
7. Success message displayed

Database Tables Used:
- users (password_hash column)
- password_reset_tokens (token, user_id, expires_at columns)
