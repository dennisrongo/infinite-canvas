-----------------------

Added comprehensive URL security validation:

1. New validation utilities in src/lib/validation.ts:
   - isValidUUID(id: string): boolean
     Validates UUID format (8-4-4-4-12) to prevent path traversal
     Returns false for strings like "../../../etc/passwd", "OR 1=1", etc.

   - sanitizeUrlParam(param: string): string | null
     Checks for path traversal attempts (.., \, /)
     Checks for URL-encoded path traversal (%2e%2e, %5c)
     Returns null if invalid, sanitized param if valid

   - isSafeRedirectUrl(redirectUrl: string): boolean
     Only allows relative URLs starting with /
     Prevents protocol-relative URLs (//evil.com)
     Prevents javascript: and data: URLs
     Validates safe character set

   - uuidSchema: Zod schema for UUID validation
