CSRF Protection (/src/lib/csrf.ts):
- generateCSRFToken(): Creates 64-byte hex token using crypto.getRandomValues
- getCSRFToken(): Returns existing token or generates new one
- validateCSRFToken(request): Compares cookie token with x-csrf-token header
- Uses timing-safe comparison to prevent timing attacks
- Tokens stored in HTTP-only cookies (24 hour expiry)

Rate Limiting (/src/lib/rate-limit.ts):
- In-memory store using Map (note: use Redis in production)
- Per-identifier tracking (IP address based)
- Automatic cleanup of expired entries every 5 minutes
- Configurable limits and block durations
- Pre-configured limits: auth (5/min), api (100/min), public (20/min)

Cookie Security (/src/lib/auth.ts):
- SameSite=strict prevents cross-site cookie sending
- HTTP-only prevents JavaScript access to tokens
- Secure flag enabled in production (HTTPS only)
- 7-day token expiration
