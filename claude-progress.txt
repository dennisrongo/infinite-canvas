Implementation Overview:
-----------------------

Added complete account deletion functionality:

1. API Endpoint (app/api/user/delete-account/route.ts):
   - DELETE /api/user/delete-account
   - Requires password confirmation
   - Verifies password before deletion
   - Deletes user and all associated data via cascade
   - Returns success message after deletion

2. Database Cascade Delete:
   - onDelete: Cascade in schema ensures all related data deleted:
     * UserSettings
     * Folders (→ Canvases → Notes → Connections, Images)
     * PasswordResetTokens
   - User deletion triggers cascade automatically

3. Settings Page UI (app/settings/page.tsx):
   - Danger Zone section with red border styling
   - Warning message listing all data to be deleted:
     * All canvases and notes
     * All folders and organizational structure
     * All images and attachments
     * Profile information
     * Settings and preferences
   - "This action cannot be undone" warning
   - Two-step confirmation:
     1. Click "Delete My Account" button
     2. Enter password and click "Confirm Deletion"
     3. Click "Yes, Permanently Delete My Account" (final warning)
   - Form validation for password field
   - Error handling for wrong password
   - Loading state during deletion
   - Automatic logout and redirect after deletion

4. Security Features:
   - Password required for confirmation
   - Wrong password blocks deletion
   - All user sessions invalidated after deletion
   - Cannot login with deleted credentials
   - Cascade delete ensures no orphaned data
